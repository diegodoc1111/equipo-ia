# Arma tu equipo de 6 empleados con IA

Guía gratis en español: <https://diegodoc1111.github.io/equipo-ia/>

Cómo crear en Claude Code un equipo de 6 agentes (investigador, redactor, guionista de anuncios, atención al cliente,
analista y revisor) con un solo mensaje, y ponerlos a trabajar juntos con Claude como jefe.

Regalo del reel "La nueva transferencia de riqueza" de [@soydiegoosorio](https://instagram.com/soydiegoosorio)
(comenta EQUIPO).

## Fuentes verificadas

- Instalación de Claude Code (comandos de Windows y Mac): <https://code.claude.com/docs/en/setup>
- Subagentes de Claude Code (carpeta `.claude/agents`, archivos con `name`, `description` y `tools`):
  <https://code.claude.com/docs/en/sub-agents>
- Planes de Claude: <https://claude.com/pricing>
